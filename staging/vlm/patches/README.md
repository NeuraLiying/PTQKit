# VLM Patches - Implementation Not Included

PTQKit v0.1.0a0 does NOT include GPTAQ-for-vision patches or implementation.

## Why Excluded

Upstream GPTAQ-for-vision license and provenance could not be verified before release.
- No public repository located
- No license file in available sources
- Cannot safely redistribute derivative patches

## What IS Included

- Phase1 and Stage2 **results** and documentation
- Reproduction guides referencing external dependencies
- Clear disclosure of implementation unavailability

Users must obtain MBQ and GPTAQ-for-vision sources independently:
- MBQ: https://github.com/thu-nics/MBQ (MIT)
- GPTAQ-for-vision: Contact upstream for access and license
